## 구현 위치
- 랭킹: `src/helpers/records.js`, `src/routes/Rankings.vue`, `src/routes/Result.vue`
- 미션: `src/helpers/missions.js` (결과만 보고 평가, 판정/점수 계산은 그대로)
- 연출: `src/javascript/fx.js` (매 프레임 객체 생성 없이 인덱스 포인터 방식)
- LAN: `electron/lan-server.js`(호스트 서버), `electron/lan-main.js`(통신 대행/자동 찾기), `electron/preload.js`, `src/helpers/lan.js`
- 대전: `src/routes/VsLobby.vue`, `src/helpers/vs.js`, `src/components/game/VsHud.vue`
- 대기 화면: `src/helpers/attract.js`, 샘플 채보 `public/charts/Doit.sample.json`
- 설정 추가: 채보 연출 효과, 대기 화면, LAN(역할/호스트 주소/PC 이름) — 전부 기본값이 기존 동작과 동일

## 대기 화면(SAMPLE PLAY) 설정
- 시간: `src/helpers/attract.js` 맨 위 `IDLE_TO_TITLE_SEC`(60), `TITLE_TO_DEMO_SEC`(10)
- 재생 곡: `src/javascript/localCatalog.js`의 `DEMO_PLAYLIST`
  ```js
  export const DEMO_PLAYLIST = [
    { chartId: "Doit-sample" },                             // 곡 전체
    { chartId: "kamui-sheet-1", from: 60, lengthSec: 40 },  // 선택: 시작 초 / 길이
  ];
  ```
- 데모 중 아무 키/클릭 → 타이틀로. 결과·기록은 남지 않음. 랭킹/대전/플레이 중에는 동작 안 함.

## 같이 고친 버그
- 곡 선택 화면(keep-alive)의 키 리스너가 다른 화면에서도 동작(결과 화면 Enter → 곡 시작으로 이동)
- LAN 호스트 끄기가 참가 PC 연결 중엔 끝나지 않던 문제
- 데모 종료 후 10초 대기 없이 바로 재시작되던 문제

## 검증 범위와 남은 확인
- 확인함: 단위 테스트, 헤드리스 브라우저 E2E(회귀 10종 포함), 실제 Electron 25(리눅스 가상 화면) 호스트 + 브라우저 참가 PC로 통합 랭킹/2인 대전/연결 끊김
- **미확인**: Windows exe 재빌드, 실제 PC 여러 대/공유기/방화벽 환경, 곡 전체(140초) 데모 연속 재생
- 실제 장비 체크리스트는 `docs/축제_LAN_운영가이드.md` 5장 참고
- 보류: 강조색 직접 지정 기능
