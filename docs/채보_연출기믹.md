# 채보 연출 기믹 작성법

채보 JSON(`public/charts/*.json`)의 `gimmicks` 배열에 아래 항목을 넣으면 해당 시간에 화면 연출이 나옵니다.

- **판정·점수·노트 위치에는 영향이 없습니다.** 그림만 바뀝니다.
- 판정선과 기어의 위치/크기는 바뀌지 않습니다(흔들기·회전·줌 같은 효과는 일부러 없음).
- 기존 `speed`/`stop` 기믹과 같은 배열에 섞어 써도 됩니다.
- 설정(곡 선택 ESC) → "채보 연출 효과"를 끄면 모든 연출이 안 나옵니다(눈부심에 민감한 사람용).
- 채보 에디터에서는 나오지 않습니다.
- 시간(`time`)은 **초 단위, 노트의 `t`와 같은 기준**입니다. 오디오 오프셋 설정도 노트와 똑같이 적용됩니다.

## 공통 필드

| 필드 | 뜻 | 비고 |
|---|---|---|
| `type` | 연출 종류 | 아래 표 |
| `time` | 시작 시각(초) | 필수. 숫자가 아니면 그 항목은 무시 |
| `duration` | 길이(초) | `endTime`으로 대신 써도 됨 |
| `color` | 색 | `#fff`, `#ff4fa3`, `rgba(255,0,0,0.5)`, `red` 형식 |
| `intensity` | 세기 0~1 | 종류별 상한이 있음(섬광 0.8) |
| `fade` | 페이드 인/아웃(초) | blackout/tint만 사용 |
| `bpm` | 박자 | pulse/beat만 사용(30~400) |

## 종류

| type | 효과 | 기본값 |
|---|---|---|
| `flash` | 화면 전체가 번쩍였다가 사라짐(기어·노트보다 뒤에 그려져 노트는 가리지 않음) | duration 0.3, `#ffffff`, intensity 0.6 |
| `blackout` | BGA를 어둡게 가림(기어와 노트는 그대로 보임) | duration 1, `#000000`, intensity 0.9, fade 0.2 |
| `tint` | 기어 안쪽 색조 변경(노트 뒤) | duration 1, `#ff4fa3`, intensity 0.25, fade 0.15 |
| `pulse` | 기어 양옆에 박자에 맞춰 맥동하는 글로우 | duration 2, `#19d3ff`, bpm 120, intensity 0.8 |
| `beat` | 박자마다 판정선 주변이 밝아졌다 식음(판정선 자체는 그대로) | duration 4, `#ffffff`, bpm 120, intensity 0.5 |

## 예시

```json
{
  "notes": [ ... ],
  "gimmicks": [
    { "type": "flash", "time": 32.0 },
    { "type": "blackout", "time": 45.2, "duration": 3.4, "fade": 0.3 },
    { "type": "tint", "time": 60.0, "duration": 8, "color": "#ffb347", "intensity": 0.2 },
    { "type": "pulse", "time": 60.0, "duration": 8, "bpm": 210 },
    { "type": "beat", "time": 71.4, "duration": 13.7, "bpm": 210, "intensity": 0.6 },
    { "type": "speed", "time": 90.0, "value": 1.5 }
  ]
}
```

팁: 곡의 하이라이트 첫 박에 `flash`, 브레이크 구간에 `blackout`, 후렴 전체에 `pulse`(곡 BPM과 같게)를 넣으면 효과가 큽니다. 같은 시간에 여러 개를 겹쳐도 됩니다.

## 확인 방법
1. 채보 JSON 저장 후 게임 실행(개발 서버라면 새로고침만 해도 반영, 채보는 매번 새로 읽음).
2. 곡 선택 ESC → 오토플레이를 켜고 해당 구간을 보면 빠르게 확인할 수 있습니다.
