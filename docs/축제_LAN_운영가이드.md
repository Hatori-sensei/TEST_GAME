# 축제 운영 가이드: 랭킹 · 미션 · LAN 대전

## 한눈에 보기
| 기능 | 들어가는 법 | 필요 조건 |
|---|---|---|
| 기록 등록 | 결과 화면에서 이름/소속 입력 → ENTER (ESC 건너뛰기) | 없음 |
| 랭킹 보드 | 곡 선택 화면 `R` (또는 `/rankings`) | 없음. LAN 설정 시 전체 PC 통합 |
| 미션 도장 | 결과 화면 아래 MISSION. 랭킹 보드 `TAB` → 미션 도장 | 없음 |
| 채보 연출 | 채보 JSON의 `gimmicks` (docs/채보_연출기믹.md) | 없음 |
| LAN 대전 | 곡 선택 화면 `V` | LAN 설정(호스트 1대 + 참가) |

LAN을 설정하지 않으면 모든 기능이 각 PC 안에서만 동작합니다(기존과 동일).

## 1. PC 배치 추천
- **공유기 1대**에 모든 PC를 유선(또는 같은 Wi-Fi)으로 연결. 학교 Wi-Fi는 PC끼리 통신을 막는 경우가 많음(클라이언트 격리) → 축제용 공유기 권장. 인터넷 연결은 필요 없음.
- **호스트 1대**: 큰 화면(TV/프로젝터)에 연결해 랭킹 보드(`/rankings`)를 띄워두는 PC. 곡이 8초마다 자동으로 넘어감. 호스트 PC로도 플레이/대전 가능.
- **참가 PC**: 플레이용 PC들.

## 2. 설정 방법(각 PC에서 1번)
곡 선택 화면 → `ESC` → 맨 아래 **LAN (여러 PC 연결)**
1. 호스트 PC: 역할 = **호스트**, PC 이름 입력(예: BOARD) → Apply. 화면에 나온 주소(예: `192.168.0.10:41235`)를 메모.
2. 참가 PC: 역할 = **참가**, PC 이름(예: 1번 PC) → **찾기**(자동 검색) 또는 주소 직접 입력 → **연결 확인**("연결됨" 확인) → Apply.
3. 설정은 저장되므로 다음 실행부터는 자동으로 연결/호스트 실행.

### Windows 방화벽
- 호스트 PC에서 처음 Apply 하면 "Windows 보안 경고(방화벽)" 창이 뜰 수 있음 → **개인 네트워크 허용** 체크 후 허용.
- 허용을 놓쳤다면: 제어판 → Windows Defender 방화벽 → 앱 허용 → RhythmPlus 체크(개인).
- 사용 포트: TCP **41235**(서버), UDP **41234**(찾기). 찾기가 안 되면 주소 직접 입력으로도 동작함.
- 네트워크 종류가 "공용"으로 잡혀 있으면 막힐 수 있음 → "개인"으로 변경.

## 3. LAN 대전 진행
1. 참가자들이 각자 PC에서 `V` → 이름/소속 입력 → ENTER(입장). 먼저 들어온 사람이 **방장**.
2. 방장: `←/→`로 곡 선택. 다른 사람: `ENTER`로 준비.
3. 방장: 모두 READY면 `ENTER` → 모든 PC가 곡을 불러온 뒤 3초 카운트다운 후 **동시에 시작**.
4. 플레이 중 왼쪽 위에 실시간 순위/점수. 대전 중엔 일시정지·게임오버 없음.
5. 끝나면 대전 결과(WIN). `R` = 내 결과 화면(여기서 랭킹 등록), 방장 `ENTER` = 로비로.
- 연결이 끊긴 PC는 OFFLINE 표시, 남은 사람끼리 계속 진행. 호스트가 꺼지면 각자 플레이는 끝까지 되고 내 결과만 확인 가능.

## 4. 관리자 기능
- 랭킹 초기화: 랭킹 화면에서 `Ctrl + Shift + Delete` → 확인. (이 PC 기록 + LAN 통합 기록 모두 삭제)
- 호스트가 잠깐 꺼져 있던 동안 등록된 기록은 각 PC에 보관됐다가, 다음에 랭킹 화면을 열거나 기록을 등록할 때 자동 전송됨.
- 데이터 위치
  - 각 PC 기록/설정: 앱 저장소(localStorage `djon.records`, `djon.settings`)
  - 호스트 통합 기록: `%APPDATA%\RhythmPlus\djon-festival-records.json` (앱 폴더 이름은 설치 방식에 따라 다를 수 있음). 축제 끝나고 백업해두면 됨.

## 5. 실제 장비에서 확인할 것(체크리스트)
이 환경(리눅스 + 가상 화면)에서는 실제 Electron 앱으로 호스트/통합 랭킹/2인 대전을 확인했지만, **Windows exe와 여러 대의 실제 PC/공유기**에서는 확인하지 못했습니다.
- [ ] `npm run electron:build`로 exe 재빌드 후 실행되는지(새 파일 `electron/` 폴더가 포함됐는지)
- [ ] 호스트 PC 방화벽 허용 후, 다른 PC에서 **찾기**로 호스트가 보이는지(안 보이면 주소 직접 입력)
- [ ] 참가 PC에서 기록 등록 → 호스트 랭킹 보드에 몇 초 안에 뜨는지
- [ ] 2~4대 대전: 동시에 시작하는지(체감), 상대 점수가 움직이는지, 끝나고 결과가 모두 뜨는지
- [ ] 대전 중 한 PC의 랜선을 뽑아도 나머지가 계속되는지(OFFLINE 표시)
- [ ] 호스트 PC를 껐다 켜도 통합 기록이 남아 있는지
- [ ] 장시간(몇 시간) 켜두었을 때 랭킹 보드가 계속 갱신되는지

## 6. 알려진 한계
- 동시 시작 정확도는 PC 간 시계 차이를 네트워크 왕복으로 보정하는 방식이라, 같은 공유기 기준 수~수십 ms 차이가 날 수 있음(각자 헤드폰으로 하면 체감 거의 없음).
- 대전 방은 1개(호스트당). 4명 초과 입장 불가.
- 이름/소속은 단순 입력이라 같은 이름을 다른 사람이 쓸 수 있음(이름+소속을 한 사람으로 취급).
- 오토플레이 결과는 랭킹 등록/미션 불가.
